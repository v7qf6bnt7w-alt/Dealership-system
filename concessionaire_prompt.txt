necesito un desarrollo de una aplicacion web basada en python para una concesionaria de automoviles, el cual consta de 2 perfiles (administrador y comprador) donde el administrador debe ingresar con usuario y contraseña, este puede crear productos con un id, un nombre, una imagen del producto, un precio, cantidad de stock disponible; si ya existe, agregar mas cantidad o disminuir, y editar la informacion del producto; en caso de que el stock alcance 0, que el producto siga en display pero sombreado y con un mensaje de 'UNAVAILABLE'. el metodo de trabajo es a la hora de tocar 'Nuevo Vehiculo' el administrador debe seleccionar la Marca, el Modelo, la Version, y luego agrega detalles extra que el quisiera y luego lo agrega, y en otro panel le aparezcan las solicitudes de compra con un ID, y que las pueda editar.
Luego el perfil publico debe ser interactivo, incoroporando imagenes (subidas por el administrador de ciertos vehiculos y con una breve descripcion del mismo) que van rotando cada cierto tiempo,  un menu de busqueda con filtro de busqueda, abajo esten las Marcas con las que trabaja y cuando el cliente toque una Marca de esas, se le reorganice la pagina con los models disponibles, luego al elegir una modelo, elija entre las versiones y que se muestre el catalogo completo de vehiculos (con las imagenes y la informacion) y que cuente con un menu de busqueda con posibilidad de filtros y busqueda por palabras. y abajo de todo luego de deslizar hacia abajo, en una seccion desitinguida de color opuesto, informacion de contacto, redes sociales, ubicaciones, y tecnologias como 'visa', 'mastercard', 'mercado pago', etc
El sistema tambien tiene que ser capaz de administrar solicitudes, por ejemplo de mas informacion por parte de un cliente, o de agendar una visita presencial para ver el vehiculo. Tras ver un vehiculo debe aparecer un boton de 'Solicitar Informacion' el cual tras apretarlo el sistema debe abrir una ventanita donde solicita datos del potencial comprador, como por ejemplo nombre, apellido, mail, y numero de telefono, etc, lo mismo si toca en 'Solicitar Visita' (en caso de solicitud de visita, preguntar (seleccionando si o no) si tambien quisiera ser incluido para un periodo de prueba de manejo del vehicullo).
